# 系統畫面截圖說明

請將展示用截圖放在此資料夾。README 已預留圖片路徑，之後手動截圖後放入同名檔案即可顯示。

建議截圖清單：

- `main-menu.png`：主選單
- `movie-management.png`：電影管理
- `showtime-management.png`：場次管理
- `seat-map.png`：座位表
- `buy-ticket-success.png`：購票成功
- `statistics.png`：營收統計

建議截圖環境：

- Windows Terminal 或 VS Code Terminal
- 執行前可先輸入 `chcp 65001`
- 視窗寬度建議拉寬，避免表格換行
