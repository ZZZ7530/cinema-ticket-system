# 使用操作指南

## 如何啟動系統

建議使用 Windows Terminal 或 VS Code Terminal。

若 PowerShell 顯示中文亂碼，先執行：

```powershell
chcp 65001
```

直接執行展示用 exe：

```powershell
.\docs\executable\cinema_ticket_system.exe
```

或自行編譯後執行：

```powershell
cmake -S . -B build -G Ninja
cmake --build build
.\build\cinema_ticket_system.exe
```

## 電影管理操作方式

從主選單輸入 `1` 進入電影管理。

```text
========== 電影管理 ==========
1. 新增電影
2. 顯示所有電影
3. 查詢電影
4. 刪除電影
0. 返回主選單
```

操作說明：

- 新增電影：輸入片名、類型、片長，系統自動產生電影 ID。
- 顯示所有電影：列出 ID、片名、類型、片長。
- 查詢電影：可輸入電影 ID 或片名關鍵字。
- 刪除電影：輸入電影 ID，若該電影已有場次，系統會禁止刪除。

## 場次管理操作方式

從主選單輸入 `2` 進入場次管理。

```text
========== 場次管理 ==========
1. 新增電影場次
2. 顯示所有場次
3. 查詢指定電影場次
0. 返回主選單
```

操作說明：

- 新增電影場次：選擇電影 ID，輸入日期、時間、影廳、rows、cols。
- 顯示所有場次：列出場次 ID、電影名稱、日期、時間、影廳、座位數、已售出座位數。
- 查詢指定電影場次：可輸入電影 ID 或片名關鍵字。

## 購票流程

從主選單輸入 `3`。

流程：

```text
顯示所有電影
-> 選擇電影 ID 或序號
-> 顯示該電影場次
-> 輸入場次 ID
-> 顯示座位表
-> 輸入座位，例如 A3
-> 選擇票種
-> 確認購買
```

票種：

- 成人票：320
- 學生票：280
- 兒童票：220

購票成功後會顯示票號，例如：

```text
[成功] 購票完成，票號：T004
```

## 退票流程

從主選單輸入 `4`。

流程：

```text
輸入票號
-> 顯示票券資料
-> 確認退票
-> 刪除票券
-> 釋放座位
```

退票成功後會顯示：

```text
[成功] 退票完成
```

## 查詢票券流程

從主選單輸入 `5`。

```text
========== 查詢票券 ==========
1. 依票號查詢
2. 顯示所有已售出票券
0. 返回主選單
```

顯示欄位：

```text
票號 | 電影名稱 | 場次 ID | 座位 | 票種 | 票價
```

## 查看座位表流程

從主選單輸入 `6`。

流程：

```text
顯示所有場次
-> 輸入場次 ID
-> 顯示座位表
```

座位符號：

```text
O = 可選座位
X = 已售出座位
```

## 營收統計流程

從主選單輸入 `7`。

```text
========== 營收統計 ==========
1. 查看總營收
2. 查看各電影售票數量
3. 查看各票種銷售數量
0. 返回主選單
```

統計內容：

- 總營收：顯示目前所有票券總金額。
- 各電影售票數量：使用電影名稱統計票券張數。
- 各票種銷售數量：顯示成人票、學生票、兒童票張數與小計金額。

## 儲存資料流程

所有新增、刪除、購票、退票都會先修改記憶體資料。

若要寫回文字檔，請在主選單輸入 `8`：

```text
[成功] 資料已儲存
```

系統離開前也會詢問是否儲存資料：

```text
離開系統前是否儲存資料 (y/n)：
```
